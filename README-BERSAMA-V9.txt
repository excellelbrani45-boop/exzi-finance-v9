EXZI FINANCE V9 — BERSAMA / KEUANGAN BERDUA

BERSAMA is a shared household/kost ledger for EXCELL × ZIZI. It is not the same thing as setting transaction owner to BERSAMA.

FEATURES
- Split Bill 50:50, percentage, or nominal manual
- Automatic expense in the real payer's personal TRANSAKSI wallet
- Automatic obligation for the other person's share
- Net balance EXCELL <-> ZIZI
- Partial/full settlement
- Shared cash (SETOR/TARIK) using owner BERSAMA
- Shared history and monthly report
SHEETS
- BERSAMA_BILLS
- BERSAMA_SPLITS
- BERSAMA_SETTLEMENTS
- BERSAMA_KAS
ACCOUNTING
1. Split bill -> actual PENGELUARAN on the payer.
2. The non-payer's share is an obligation only; their wallet does not change until settlement.
3. Settlement -> paired TRANSFER rows; it changes both wallets without inflating income/expense.
4. Shared cash -> paired TRANSFER rows between personal wallet and BERSAMA wallet.
